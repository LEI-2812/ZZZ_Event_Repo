# 비스트-비트 스테이션 · Unity 구현

Unity 6000.6.0f1 / Windows / uGUI + Input System. 제작 기준: 제공된 제안서 38쪽, UI 문서 64쪽, 데이터 테이블 설명문서 23쪽.

## 실행

Unity 메뉴 **Beast Beat → 이벤트 씬 만들기 또는 열기**를 선택한 뒤 Play.
씬: `Assets/BeastBeat/Scenes/BeastBeatStation.unity`.
이벤트 이동 → 방부 도감 / 입양 → 방부 선택과 입양 → 챔피언 리그 → 배틀 시작.
첫 배틀에는 조작 안내가 표시됩니다. 마우스 클릭과 스크롤을 사용하며 Esc로 팝업을 닫거나 일시정지합니다.

현재 프로젝트의 SampleScene은 덮어쓰지 않습니다. 이벤트 전용 씬이 빌드 목록에 추가됩니다.
실제 젠레스 존 제로 계정이나 서버와 연결하지 않는 로컬 플레이 구현입니다. 보상도 로컬 인벤토리에만 지급됩니다.

## 문서에서 확정되지 않아 보완한 사양

아래는 원문 확정 사양이 아닙니다. `Resources/BeastBeat/game-data.json`에서 조정 가능합니다.

- 피해량: 공격력 × 기술 배율 × 상성 / (1 + 방어력 × 0.012), 반올림, 최소 1.
- 속성 배율: 유리 1.5, 순환 불리 0.65, 기타 1.0. 전기/에테르는 서로 1.5.
- 기본 공격 배율 4.5, 속성 공격 5.4, 응급수리 최대 HP 30%. PP 15/8/5.
- 속성 공격의 화상·빙결·마비 부여 확률 25%. 화상은 최대 HP 6% 지속 피해, 빙결은 다음 행동 불가 후 해제, 마비는 25% 행동 불가. 지속 2턴.
- 모든 PP 소진 시 반동을 받는 발버둥 제공. 상대도 PP를 소모.
- 자발적 선수 교체는 상대의 공격 턴을 소모하고, 기절 후 강제 교체는 무료. 상대 방부를 쓰러뜨린 턴에 새 상대가 즉시 공격하지 않음.
- 동시 전멸은 패배. 패배와 도주는 보상 없음. 배틀 시작 시 전원 회복.
- 경험치 요구량 100 + (현재 레벨 − 1) × 20. 최고 레벨 20. 방부 레벨은 플레이어 레벨 이하.
- 방부 LV10에서 코어 진화: 외형에 발광 장식 추가, 능력치 보너스. 진화 이름/진화 종족 데이터는 미제공이라 원래 이름 유지.
- 새 입양 방부는 플레이어 레벨로 합류. 첫 3속성은 LV1, 나머지는 LV2–8 해금.
- 스테이지 상세 NPC/대사/적 파티/레벨, 수량이 없는 보상과 업적 목표를 플레이 가능한 샘플 데이터로 보완.
- UI의 워밍업 화면에 여러 목록 예시가 있지만 제안서 진행 흐름에 맞춰 워밍업은 튜토리얼 1경기로 구성.
- 특별 보상 조건은 UI p51의 구체적 조건인 ‘모든 업적 보상 수령’을 적용. 여기에는 결승 클리어와 도감 완성이 포함됨.
- 이벤트 종료일 미제공: 최초 로컬 실행 시점부터 14일 동안 한정 보상 활성. 기본 업적/레벨 보상은 만료되지 않음. 단말 시계를 사용하며 서버 검증 없음.
- 업데이트가 없는 독립형 버전이므로 NEW 알림은 별도로 생성하지 않음.
- 데이터 설명 PDF p3의 Google 스프레드시트는 접근 실패. 별도 원본 테이블 수치와 일치한다고 보장하지 않음.

## 데이터와 코드

- `BeastBeatData.cs`: 정수 코드, 정적 마스터 데이터, 유저 저장 모델.
- `ProgressService.cs`: 입양/편성/해금/성장/보상/저장. 정적 데이터와 유저 상태 분리.
- `BattleEngine.cs`: 프레임 및 화면과 독립적인 턴 처리. 테스트용 난수 시드 주입 가능.
- `BeastBeatApp.cs`: 진입/메인/스테이지/도감 및 UI 공통 구성.
- `BeastBeatBattleUI.cs`, `BeastBeatRewardsUI.cs`: 전투 연출·모달·결과·보상.
- `BangbooPortraits.cs`: 교체 가능한 임시 3D 방부 초상 생성.
- `Editor/BeastBeatSetup.cs`: 씬 구성, 규칙 검증, 전체 리그 시뮬레이션.

JSON은 원문의 관계를 따르는 테이블 배열입니다. 원문의 예시 `achievement_rewards.level_id`는 설명의 의미에 맞게 `owner_id`로 정리했습니다. `pause_list`의 중복 스테이지 정보는 실행 중 StageData 참조로 처리하고 `party`는 유저 저장 데이터로 분리했습니다. SQL 서버나 ORM은 사용하지 않습니다.

## 저장 및 아트

저장 위치: `Application.persistentDataPath/beast-beat-v1.json`.
임시 파일 작성 후 원자적 교체, 이전본 `.bak`, 손상본 별도 보존 및 백업 복구. 저장 실패는 화면 하단 안내. 신규 테스트는 별도 임시 경로를 사용합니다.

아케이드/경기장 배경은 사용자가 제공한 UI PDF에 포함된 이미지를 추출했습니다. 배경과 원문 캐릭터/IP의 권리는 해당 권리자에게 있습니다. 방부는 원본 모델이 아닌 색상·액세서리를 달리한 임시 3D 모델입니다. 원문에 등장하는 샤크부 등 UI 예시 대신 마스터 데이터 문서의 10종을 사용했습니다.
Windows의 맑은 고딕을 런타임에 사용하므로 다른 운영체제 배포 시 한국어 폰트 자산을 추가해야 합니다. 외부 패키지 다운로드와 원본 게임 설치는 필요하지 않습니다.

## 검증

Unity 메뉴 `Beast Beat → 검증 → 핵심 규칙 테스트` / `전체 리그 시뮬레이션`.
전체 리그 시뮬레이션에서 실패 시 진행 불가 스테이지를 출력하며, 자동 재도전 육성이 필요할 수 있습니다. 화면 및 실행 검증 결과는 배포 시 별도 기록합니다.

## 📌 프로젝트 소개
게임 '젠레스 존 제로'의 이벤트 <b><비스트 비트-스테이션></b>을 재현하며 게임 시스템과 UI를 구현하는 프로젝트입니다. </br>
기획서 '젠존제 신규 이벤트 제안서'를 기준으로 작업했으며, 실제 게임 플레이가 가능하도록 제작했습니다.
</br></br>

## 📌 개발 폴더 구조

| **폴더명** | **폴더 설명** |
| ---------- | ------------- |
| `Build` | 게임 실행을 위한 빌드 파일 |
| `Develop` | 게임 개발에 사용하는 프로젝트 파일 |
| `Document` | 게임 기획서 및 관련 문서 |
</br>

## 📌 실행 방법

### 1. Build 파일로 실행
1. 배포된 **Build 파일**을 다운로드합니다.
2. 압축 파일을 해제합니다.
3. 압축을 해제한 폴더에서 **ZZZ Event Project** 파일을 실행합니다.

> 실행 파일과 함께 제공된 데이터 폴더 및 파일은 같은 위치에 유지해 주세요.

### 2. 웹 빌드로 실행

1. **[웹 빌드 플레이하기](웹빌드_링크)** 링크에 접속합니다.
2. 로딩 후 웹 브라우저에서 게임을 플레이할 수 있습니다.

</br>

## 📌 기술 스택

| **구분** | **기술** | **활용 목적** |
| -------- | -------- | ------------- |
| 게임 엔진 | Unity | 게임 시스템 및 이벤트 콘텐츠 구현 |
| 개발 언어 | C# | 게임 로직, 입력 처리, 이벤트 진행 구현 |
| UI | Unity UI | 메뉴, 안내 화면, 플레이 UI 구성 |
| 웹 빌드 | Unity WebGL | 웹 브라우저에서 실행할 수 있는 빌드 제작 |
| 버전 관리 | Git / GitHub | 소스 코드 관리 및 변경 이력 기록 |
| 개발 도구 | Visual Studio 또는 Rider | 스크립트 작성 및 디버깅 |
